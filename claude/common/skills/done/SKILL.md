# /done — 완료 점검

아래를 순서대로 확인하고 결과를 표로 보고한다. 통과하지 못한 항목이 있으면 완료라고 말하지 않는다.

1. **변경 범위**: `git status`, `git diff`로 의도한 파일만 바뀌었는지 본다. 요청과 무관한 변경이 있으면 되돌리거나 보고한다.
2. **빌드·테스트**: `<<결정: 빌드/테스트 명령. 예) ./gradlew test>>`를 실행하고 결과를 그대로 보고한다. 실행하지 못했으면 못 했다고 쓴다.
3. **규칙 점검**: `/review-rules`로 변경 파일을 설치된 규칙과 대조한다.
4. **구조 점검**(spring-boot): `/audit-structure`가 설치되어 있으면 실행한다.
5. **비밀 값**: 변경분에 키, 비밀번호, 토큰이 없는지 확인한다.
6. **보고**: 한 일, 확인한 방법, 확인하지 못한 것, 남은 위험을 적는다.

commit과 push는 하지 않는다. 사용자가 요청하면 `git-convention` 규칙을 따른다.
