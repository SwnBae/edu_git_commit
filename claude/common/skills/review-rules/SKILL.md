# /review-rules — 규칙 대조 리뷰

읽기 전용이다. 파일을 수정하지 않는다.

1. 대상 결정: 인자가 있으면 그 파일/디렉터리, 없으면 `git diff`(작업 중 변경)와 `git diff --cached`.
2. `.claude/rules/` 아래 규칙을 모두 읽는다. 대상 파일에 적용되는 규칙(`paths` 일치)만 추린다.
3. 변경 파일을 읽고 규칙 항목별로 위반 여부를 확인한다. 추측하지 않고 코드에서 확인한 것만 적는다.
4. 보고 형식(위반이 있을 때만):

   | 규칙 | 위치(파일:줄) | 위반 내용 | 제안 |
   |---|---|---|---|

5. 위반이 없으면 어떤 규칙을 대조했는지만 짧게 쓴다.
6. 규칙끼리 충돌하거나 규칙이 모호해서 판단할 수 없는 항목은 "판단 보류"로 따로 적는다.
7. 규칙에 없는 개인 취향은 위반으로 보고하지 않는다.
